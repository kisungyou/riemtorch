# riemtorch 0.3.0 release evidence

The source archive is at `../../../../riemtorch_0.3.0.tar.gz`.
`check.log` and `tests.Rout` record the installed package check. `comparison.csv`
contains this stage's comparison status, separate from later implementation.
`results.csv` and `kernel-costs.csv` are benchmarks run against this exact package
version on CPU float64. Their environment and limitations are in `environment.txt`.
The later eight-family independent suite is associated with release 0.6.0 only.
